# 🍔 Foodie Express

Foodie Express is a frontend food ordering website built using **HTML, CSS, and JavaScript**.

This project is designed to demonstrate core frontend development concepts including:

* HTML Structure
* CSS Styling
* JavaScript Fundamentals
* Variables & Data Types
* Input & Output
* Operators
* Conditional Statements
* Loops
* Functions
* DOM Manipulation
* Event Handling

Users can browse food items, view menus, place orders, calculate bills, manage profiles, and interact with a modern restaurant-style user interface.

---

## Home Page

* Dynamic Food Cards
