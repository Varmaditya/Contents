📘 Personal Notebook / Reminder App (Python + Tkinter)

A simple and elegant daily note-taking and reminder application built using Python’s Tkinter.
This app allows users to create, search, update, and delete notes with automatic timestamps. All data is saved permanently using file handling.

🛎️ Features

✔ Add text-based notes with automatic date & time
✔ Edit or delete any saved note
✔ Search notes by keywords
✔ Scrollable table view for all notes
✔ Permanent storage in notes.txt
✔ Modern UI with custom theme
✔ No database required — uses file handling
