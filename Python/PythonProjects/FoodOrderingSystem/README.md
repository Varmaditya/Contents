🍕 Food Ordering System (Python + Tkinter)

A simple and interactive Food Ordering Application built using Python’s Tkinter library.
This app allows users to order food items, apply discounts, view cart details, and generate a bill with GST.

🛠️ Features

✔ User-friendly modern UI
✔ Add food items with quantities
✔ Automatic GST calculation (12%)
✔ Apply discount coupons (SAVE50, NEW10, FEST20)
✔ View cart with price calculation
✔ Checkout & save bill as a text file
✔ Attractive rounded buttons & custom theme
