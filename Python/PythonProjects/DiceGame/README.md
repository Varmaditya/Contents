🎲 Dice Game Tournament (Python + Tkinter)

A fun, intermediate-level multiplayer dice tournament game created using Python and Tkinter.
Players compete by rolling animated dice, collecting scores, and winning based on a set of rules.
The game features a clean UI, sound effects, animations, and a scoreboard.

🕹️ Game Features

✔ Multiplayer support (up to 4 players)
✔ Animated dice roll
✔ Sound effects (ON/OFF toggle)
✔ Scoreboard tracking
✔ Bonus rules for dice outcomes
✔ Themed UI with rounded buttons
✔ Winner declaration + reset option
